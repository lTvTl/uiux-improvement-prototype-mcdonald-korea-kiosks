## 1. 프로젝트 개요

본 프로젝트는 맥도날드 매장의 무인 주문 키오스크를 이용하는 **고령 고객(만 68세 대표 페르소나)**이 겪는 인터랙션 장벽과 루프 단절 문제를 해결하기 위한 고충실도 인터랙티브 웹 프로토타입입니다. 

현행 키오스크의 사용 맥락과 인지적 특성을 분석한 관찰 근거를 바탕으로, 과도한 시각적 자극을 줄이고 핵심 조작 단계를 직관적으로 단순화하여 고령자의 자립적 주문 경험을 지원합니다.

## 2. 해결한 3대 핵심 문제점 및 To-be 개선안

| 구분 | 기존 As-is 문제점 (관찰 근거) | 개선 To-be 솔루션 (본 프로토타입) |
|---|---|---|
| **시작 단계** | **E01/C01**: 상단 전면 동적 프로모션 광고로 인해 하단 시작 버튼을 찾지 못하고 8초 이상 체류 및 작동 여부 혼란 | **광고 25% 축소 & 초대형 시작 버튼**: 광고 면적을 상단으로 제한하고, 화면 중앙에 고대비의 초대형 '주문 시작하기 (터치하세요)' 버튼 배치 (부드러운 펄스 애니메이션) |
| **옵션 변경** | **E02/C02**: 메뉴 이미지에 비해 토핑/사이드 변경 버튼이 작고 텍스트로 숨겨져 있어 기본 메뉴로 담았다가, 삭제 후 재주문하는 우회 루프(2분 지연) 발생 | **변경 버튼 면적 200% 확대 & 강조 테두리**: '사이드 변경하기' 버튼을 2배 확대하고 골드 테두리(`border-4`) 및 뱃지 적용, 치즈스틱 원클릭 변경 모달 제공 |
| **결제 단계** | **E03/C03**: 결제 직전 예상치 못한 '테이블 텐트/진동벨 번호 입력' 강제로 인해 조작 오류로 오인, '이전' 버튼 연타하며 결제 루프 단절 | **카운터 직접 수령 기본값 자동화**: 불필요한 추천 메뉴 팝업을 전면 생략하고, 카운터 직접 수령을 기본값으로 지정하여 결제하기 클릭 즉시 카드 삽입 화면으로 직행 (이동약자를 위한 테이블 서빙 보조 링크 유지) |
| **하드웨어 피드백** | 마그네틱/IC칩 방향 혼동으로 인한 투입 오류 | **다감각 피드백**: 금색 IC칩 방향을 직관적으로 보여주는 시각 모션 및 오류 시 비프음(음성) 안내 제공 |

## 3. 주요 기능 및 과업 흐름 (Critical Path)

1. **시작 화면**: 고령자 친화 모드 적용, 중앙 초대형 주문 시작 버튼
2. **식사 장소 선택**: '매장 식사' vs '포장 주문' 큼직한 2분할 버튼
3. **메뉴 탐색**: 버거 세트 카테고리 내 '빅맥 세트' 직관적 노출
4. **옵션 상세 및 사이드 변경**: 면적 200% 확대 버튼, 골든 모짜렐라 치즈스틱(+500원) 실시간 반영
5. **장바구니 확인 & 즉시 결제 진입**: 1번 카운터 수령 기본값 배너, 추천 팝업 생략
6. **신용카드 결제 시뮬레이션**: IC칩 방향 시각 모션 그래픽, 정방향/역방향 모의 투입 테스트 및 소리 피드백
7. **주문 완료 및 성과 리포트**: 60px 대형 주문번호(234번) 표시 및 실시간 과업 완료 시간 측정 결과 리포트

---

## 4. 정량적 검증 목표 (SMART)

- **결제 완료 소요 시간**: 기존 가상 기준 58초 → **30초 이하 달성**
- **결제 재시도(이전 회귀) 횟수**: 기존 평균 0.8회 → **평균 0.2회 이하로 완전 개선**
- **옵션(사이드) 변경 성공률**: 기존 55% → **90% 이상 향상**

## 1. 프로젝트 개요

본 프로젝트는 맥도날드 매장의 무인 주문 키오스크를 이용하는 고객이 겪는 복잡한 인터랙션 장벽과 조작 루프 단절 문제를 해결하기 위한 고충실도 인터랙티브 웹 프로토타입입니다.

누구나 쉽게 이용할 수 있는 유니버설 디자인을 기반으로, 과도한 시각적 자극을 줄이고 이해하기 어려운 외래어를 알기 쉬운 한국어로 전환하였습니다. 또한 기존에 유용하게 사용되던 기능(테이블 번호표 서비스 등)은 그대로 보존하면서, 불필요한 강제 입력 단계를 기본값 처리로 간소화하여 빠르고 자립적인 주문 경험을 제공합니다.

---

## 2. 해결한 3대 핵심 문제점 및 개선안

| 구분 | 기존 문제점 (관찰 근거) | 개선 솔루션 (본 프로토타입) |
|---|---|---|
| **시작 단계** | **E01/C01**: 상단 전면 동적 프로모션 광고로 인해 하단 시작 버튼을 찾지 못하고 체류 지연 및 작동 여부 혼란 | **광고 25% 축소 & 초대형 시작 버튼**: 광고 면적을 상단으로 제한하고, 화면 중앙에 고대비의 초대형 '주문 시작하기 (누르세요)' 버튼 배치 (부드러운 펄스 애니메이션) |
| **옵션 변경** | **E02/C02**: 메뉴 이미지에 비해 토핑/사이드 변경 버튼이 작고 텍스트로 숨겨져 있어 기본 메뉴로 담았다가, 삭제 후 재주문하는 우회 루프 발생 | **함께 먹는 메뉴 변경 버튼 200% 확대 & 강조 테두리**: '다른 메뉴로 바꾸기' 버튼을 2배 확대하고 골드 테두리(`border-4`) 및 뱃지 적용, 치즈스틱 원클릭 변경 모달 제공 |
| **수령 방식 및 결제** | **E03/C03**: 결제 직전 예상치 못한 '테이블 텐트/진동벨 번호 입력' 강제로 인해 조작 오류로 오인, '이전' 버튼 연타하며 결제 루프 단절 | **카운터 직접 수령 기본값 자동화 & 테이블 텐트 기능 온전 보존**: 일반 고객은 계산대 직접 수령을 기본값으로 하여 즉시 결제로 직행. 자리 서빙을 원하는 고객은 '자리로 직원 배달 받기' 선택 시 키오스크 옆 테이블 텐트 번호표를 집어 번호를 입력하는 실제 프로세스 정상 동작 |
| **하드웨어 피드백** | 마그네틱/IC칩 방향 혼동으로 인한 카드 투입 오류 | **쉬운 한국어 & 다감각 피드백**: '카드의 노란색 금색 네모 부분' 안내 및 시각 모션, 오류 투입 시 경고음(비프음) 제공 |

## 3. 주요 기능 및 과업 흐름 (Critical Path)

1. **시작 화면**: 과도한 자극을 줄인 상단 광고, 화면 중앙의 초대형 주문 시작 버튼
2. **식사 장소 선택**: 외래어(테이크아웃 등)를 배제한 '매장에서 식사' vs '포장해 가기' 명확한 2분할 버튼
3. **메뉴 탐색**: 쉬운 한국어 탭(세트 메뉴, 단품, 함께 먹는 메뉴, 음료) 및 '빅맥 세트' 직관적 노출
4. **옵션 상세 및 함께 먹는 메뉴 변경**: 면적 200% 확대 버튼, 골든 모짜렐라 치즈스틱(+500원) 실시간 반영
5. **장바구니 확인 & 수령 방식 선택**:
   - 기본값: [계산대에서 직접 받기] (추천 · 빠른 결제 직행)
   - 선택 옵션: [자리로 직원 배달 받기 (테이블 텐트 번호표 사용)] → 실제 삼각 텐트 번호표 번호 키패드 입력 모달 지원
6. **신용카드 결제 시뮬레이션**: 금색 앞면 투입 시각 모션 그래픽, 올바른 투입/반대 투입 모의 테스트 및 소리 피드백
7. **주문 완료 및 수령 안내**: 대형 주문번호(234번) 표시 및 수령 방식(계산대 수령 / 테이블 번호표 서빙)에 따른 맞춤형 완료 안내

## 4. 정량적 검증 목표 (SMART)

- **결제 완료 소요 시간**: 기존 가상 기준 58초 → **30초 이하 달성**
- **결제 재시도(이전 회귀) 횟수**: 기존 평균 0.8회 → **평균 0.2회 이하로 완전 개선**
- **옵션(사이드) 변경 성공률**: 기존 55% → **90% 이상 향상**

- 관찰 근거에서 사용자 중심 문제문장을 도출한다.

## 3. 관찰 근거

|---|---|---|---|---|

## 4. 문제문장

| 필수 요소 | 작성 내용 |
|---|---|
| 사용자 | 68세 노년층 고객은 |
| 사용 맥락 | 뒤에 대기자가 있어 빠른 결제 압박을 받는 상황에서 |
| 달성하려는 목표 | 원하는 토핑으로 변경하여 카드 결제를 완료하려 하지만, |
| 관찰된 장벽 | 광고에 묻힌 작은 버튼 크기와 결제 후 이어지는 복잡한 부가 서비스 선택 과정 때문에 |
| 현재 결과 | 결제 시간이 늘어나고 이전 단계로 반복해서 돌아가는 문제를 경험한다. |

최종 문제문장:

> 68세 노년층 고객은 뒤에 대기자가 있어 빠른 결제 압박을 받는 상황에서 원하는 토핑으로 변경하여 카드 결제를 완료하려 하지만, 광고에 묻힌 작은 버튼 크기와 결제 후 이어지는 복잡한 부가 서비스 선택 과정 때문에 결제 시간이 늘어나고 이전 단계로 반복해서 돌아가는 문제를 경험한다.

## 5. 방법론 선택

| 방법론 | 적합한 이유 | 부족한 점·보완 방법 |
|---|---|---|
| HCD | 실제 매장에서 사용자가 겪는 작은 글씨, 복잡한 단계를 중심에 두고 해결책을 반복 평가하기에 적합함 | 사용자의 심리적 압박감을 수치화하기 어려우므로, 정성적 질문을 보완 |
| 디자인 씽킹 | 혼잡한 환경에서 고령자가 느끼는 당혹감과 소외감에 깊이 공감하고 문제를 재정의하는 데 유리함 | 공감에만 머무르지 않도록 구체적인 UI(버튼 크기, 결제 단순화) 개선 아이디어로 구체화함 |
| Lean UX | '결제 과정을 단순화하고 버튼 크기를 키우면 주문 시간이 줄어들 것이다'라는 가설을 빠르게 검증 가능함 | 사용자 정보탐색 과정이 누락될 수 있으므로, 초기 사용자 행동 근거를 단단히 설정하여 보완 |

선택한 접근과 이유:

> 키오스크 사용 시 노년층이 실제로 겪는 시각적 가시성 부족과 루프 단절 문제를 구체적인 화면 개선으로 해결하고, 이를 사용자 평가로 반복 검증하는 것이 가장 확실한 방법이기 때문이다.

## 6. 핵심 아이디어 3프레임

| 프레임 | 사용자 목표·행동 | 화면·시스템 반응 | 확인할 가정 |
|---:|---|---|---|
| 1. 시작 | 주문하기 버튼을 누른다 | 광고를 줄이고 폰트와 크기를 키운 '주문하기' 버튼을 화면에 표시 | 버튼 크기와 명도를 조절하면 탐색 시간이 줄어든다 |
| 2. 핵심 행동 | 원하는 토핑 및 사이드 음료를 변경한다 | 상품 이름/크기를 줄이고 변경 버튼의 크기와 폰트를 키움, 강조 애니메이션 제공 | 시각적 강조 효과가 원하는 메뉴 변경 성공률을 높인다 |
| 3. 완료·피드백 | 주문 내역을 확인하고 결제를 완료한다 | 부가 서비스(테이블 텐트 등)를 기본값으로 설정하여 즉시 결제 대기 화면으로 전환 | 결제 과정을 단순화하면 이전 화면으로 돌아가는 이탈률이 줄어든다 |

## 8. 검증 계획

| 항목 | 작성란 |
|---|---|
| 가장 위험한 가정 | 결제 과정을 단순화하기 위해 부가 서비스를 숨길 경우, 테이블 서비스가 꼭 필요한 사용자(장애인, 노약자)가 소외되지 않을 것이다. |
| 검증할 핵심 가설 | 버튼 크기를 키우고 결제 이후 부가 서비스를 기본값 지정으로 단순화하면, 키오스크에 익숙하지 않은 고객의 평균 주문 시간이 단축되고 결제 재시도 횟수가 줄어들 것이다. |
| 프로토타입 범위 | 시작 화면부터 메뉴 선택, 토핑 변경을 거쳐 카드 결제 완료 및 영수증 출력까지의 전체 루프 |
| 참여자와 공통 과업 | 65세 이상, 맥도날드 키오스크 첫 사용자인 10명. 원하는 메뉴를 선택 후 토핑을 변경하여 결제까지 성공하기 |
| 지표 1·측정 방법·목표값 | 결제 과정 재시도 횟수 / 결제화면에서 다시 돌아오는 횟수 측정 / 평균 0.2회 이하 (가상) |
| 지표 2·측정 방법·목표값 | 전체 완료 시간 / 결제하기 버튼 선택부터 승인 완료까지 초 단위 측정 / 평균 30초 이하 (가상) |
| 실패로 판단할 조건 | 평균 완료 시간이 90초를 초과하거나, 직원 도움 요청률이 20%를 초과할 경우 |

## 9. 개인 비판 검토

| 질문 | 답변 |
|---|---|
| 근거 없이 내가 추정한 것은 무엇인가? | 개선된 화면이 기존 고객이나 매장 환경(소음, 기기 고장 등)의 근본적인 문제까지 모두 해결해 줄 것이라고 가정했다. |
| 이 해결안이 소외할 수 있는 사용자는 누구인가? | 거동이 불편하여 직원의 테이블 텐트 서비스가 필수적인 사용자(장애인, 임산부 등)가 숨겨진 부가 서비스 기능을 찾지 못해 소외될 위험이 있다. |
| 기술보다 정책·정보 품질 문제는 없는가? | 매장 내의 심한 소음, 뒤에 늘어선 대기열로 인한 압박감, 고장 난 키오스크 등 오프라인 매장의 환경 및 하드웨어 유지보수 문제가 상존한다. |
| 반대 해결안 하나와 장점은 무엇인가? | 직원 호출 전용 하드웨어 버튼을 키오스크 전면에 부착하는 방안. 디지털 소외계층의 주문 실패를 가장 확실하게 방지할 수 있다. |

## 2. 5W1H 문제 정의

| 질문 | 작성란 |
|---|---|
| Who: 누구의 문제인가? | 키오스크 사용 경험이 있지만 맥도날드 매장에서의 키오스크 주문이 낯설거나 어려운 68세 등 고령층/노년층 고객 |
| What: 어떤 과업·문제인가? | 화려한 광고 속 주문하기 버튼 탐색 지연, 찾기 어려운 토핑/사이드 변경, 그리고 결제 직후 이어지는 복잡한 부가 서비스(테이블 서비스, 진동벨 번호 입력 등) 선택 단계에서의 혼란 및 루프 단절(이전 화면 회귀, 결제 재시도) |
| When: 언제 발생하는가? | 앞서 설명한 고객층의 맥도날드 키오스크 주문시 발생 |
| Where: 어디서 발생하는가? | 맥도날드 매장 내부 터치스크린 키오스크 앞 |
| Why: 왜 중요한가? | 주문 반복·포기 및 직원 호출을 호출하는 고령층의 고객발생함. 매장 대기열 병목과 운영 효율 저하 및 고객층 이탈을 초래하기 때문 |
| How: 현재 어떻게 대처하는가? | 원치 않는 기본 토핑대로 주문하거나, 키오스크 주문을 포기하고 직원에게 도움을 요청함 |

### 문제 근거

| 근거 ID | 관찰·자료 내용 | 출처 | 신뢰도·한계 |
|---|---|---|---|
| E01 | 시작 화면에서 화려한 광고에 비해 '주문하기' 버튼이 작고 평범하여 시작 버튼을 찾지 못하고 오래 머무름 | 가상 행동 시나리오 및 인터넷 자료조사 | 실제 고령층의 탐색 소요 시간과 발생 빈도는 추가 조사가 필요함 |
| E02 | 메뉴 이름과 이미지에 비해 토핑 및 사이드/음료 변경 버튼 크기가 작아, 변경하지 못하고 지나치거나 헤매다 주문함 | 가상 행동 시나리오 및 인터넷 자료조사| 사용자의 시력 저하 수준 및 디지털 기기 친숙도에 따른 개인차 존재 |
| E03 | 주문 확인 후 결제 단계에서 테이블 서비스(테이블 텐트 번호, 진동벨 번호 등) 선택 화면이 길게 이어져 당황하여 이전 화면으로 돌아감 | 가상 화면 시나리오 및 인터넷 자료조사 분석 | 실제 매장의 테이블 서비스 이용률 통계 및 기본값 적용시 고객 선호도 확인 필요 |

## 3. 프로젝트 목표

최종 목표:

> 6주 안에 키오스크 경험이 있는 고령층 사용자가 맥도날드 키오스크에서 세트 메뉴 토핑/사이드 변경 및 카드 결제를 수행할 때, 현재 가상 기준 58초인 결제 완료 소요 시간을 30초 이하로 단축하고, 0.8회인 결제 과정 재시도 횟수를 0.2회 이하로 개선한다.

| SMART 기준 | 확인 내용 |
|---|---|
| Specific | 키오스크 경험이 있는 고령층 고객이 겪는 '토핑/음료 변경 버튼 미인식'과 '결제 직후 부가 서비스 단계로 인한 이전 화면 회귀'를 해결하는 UI/UX 개선에 집중함 |
| Measurable | 결제 완료 시간(58초→30초), 결제 재시도 횟수(0.8회→0.2회), 버튼 클릭 성공률(55%→90%), 직원 도움 요청률(50%→20%) 등 구체적 정량 지표로 측정함. 다만 해당 과정은 실제 과정을 확인하기 어려우므로 가상 기준으로 임의로 지정함 |
| Achievable | 실제 키오스크에 적용 및 문제 해결 척도를 판단하기 어렵다는 현실적 문제가 발생하지만 현재 문제를 판단하고 수정방향을 지정하기는 가능함 |
| Relevant | 인터랙션 분석에서 도출된 핵심 문제(가시성 부족, 루프 단절)를 직접 해결하여 고령자의 디지털 자립도를 높임 |
| Time-bound | 6주 학기 프로젝트 일정에 맞춰 주차별 명확한 마일스톤을 준수함 |

|---|---|---|

| 최종 산출물 | 형식·링크 | 완료 기준 |
|---|---|---|
| 연구 자료 | 사용자 여정 맵 및 인터랙션 루프 분석서  | 5W1H, 근거 3건(E01~E03), 5단계 루프 단절 원인 분석 명시 |
| 프로토타입 | 인터랙티브 고충실도 프로토타입 링크 | 시작 화면 → 메뉴 선택 → 토핑 변경 → 기본값 결제 → 영수증 출력 전 과정 구현 |
| 평가 결과 | 65세 이상 10인 대상 사용성 평가(UT) 결과 보고서 | 완료 시간, 재시도 횟수, 도움 요청률 전후 비교 및 SEQ 점수 산출 완료 |

## 7. 개인 작업 관리

| 업무 영역 | 내가 수행할 일 | 도움받을 수 있는 사람·자료 | 의사결정 기준 |
|---|---|---|---|
| 사용자 연구 | 매장 환경 및 사용자 행동 관찰, 인터랙션 루프 6단계 분해 | 맥도날드 실제 이용자, Youtube를 이용한 실 경험자의 패턴 분석 | 주관적 편견을 배제하고 관찰 가능한 행동 근거를 우선함 |
| 디자인 | 광고 영역 재배치, 메뉴 및 변경 버튼 시각 위계 설계, UI 컴포넌트화 | 고령자 접근성 지침, 디자인 시스템 가이드, 다른 패스트푸트 키오스크 | 고령자 페르소나를 이용한 경험과 기본 사용자의 UI/UX 경험 기반 구현 |
| 프로토타입 | 옵션 변경 및 결제 플로우 인터랙션 구현, UX/UI 구현 | 템플릿 에셋 | 실제 터치스크린 조작감과 결제 피드백의 충실한 재현 |
| 평가·분석 | 사용성 평가 시나리오 작성, 정량/정성 데이터 수집 및 비교 분석 | 클라이언트 페르소나, 동료 검토 | 사전에 정의한 가설 목표값 달성 여부 |

과업이 지연될 때 축소할 최소 범위:

> 일정 지연 발생 시, 세부 부가 메뉴 탐색이나 다양한 결제 수단(간편결제, 모바일 쿠폰 등) 구현을 제외하고, **'단일 세트 메뉴 선택 → 토핑/음료 1회 변경 → 기본값(카운터 수령) 결제 완료'**로 이어지는 1개 핵심 과업(Critical Path)만 집중 구현하여 사용성 검증을 완결한다.

|---|---|
| 문제와 근거를 30초 안에 설명했는가? | 예. 맥도날드 키오스크에서 고령 고객이 화려한 광고 속 작은 버튼과 결제 직후 이어지는 복잡한 부가 서비스 선택으로 인해 결제 시간이 58초 이상 지연되고 이전 단계로 돌아가는 문제를 명확히 설명함. |
| 사용자 가치와 성공 지표가 연결되는가? | 예. 변경 버튼 시인성 확대와 결제 플로우 단순화를 통해 결제 시간 단축(58초→30초), 재시도 횟수 감소(0.8회→0.2회), 직원 도움 요청률 감소(50%→20%)를 달성하여 고령자의 자립적 주문 경험이라는 가치와 직결됨. |
| 1인이 6주 안에 수행 가능한 범위인가? | 예. 하드웨어 개조나 백엔드 연동을 제외하고, 가상의 키오스크를 예상하며 페르소나를 이용한 변경값 도출 |
| 가장 위험한 가정을 먼저 시험하는가? | 예. 부가 서비스(테이블 서비스)를 기본값으로 단순화할 때 기존 서비스 이용한 사용자들의 불편한 점을 페르소나를 이용하여 빠르게 판단함. |

## 10. 제출 전 점검

- [✓] 문제 근거와 목표가 연결된다.
- [✓] 목표에 현재값·목표값·기한이 있다.
- [✓] 포함·제외 범위가 구체적이다.
- [✓] 매주 산출물과 완료 기준이 있다.
- [✓] 사용자 검증이 최종 제출보다 앞선다.
- [✓] 윤리·접근성·개인정보 위험을 포함했다.

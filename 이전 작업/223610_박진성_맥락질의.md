# Chapter 05 맥락질의 인터뷰 워크북 — 1인용

- 작성자·학번: 박진성 / 223610
- 과제명: 맥도날드 주문 키오스크의 고령 사용자 경험 개선을 위한 맥락질의 인터뷰
- 연결 슬라이드: [05 맥락질의 인터뷰 기법](../slides/05_맥락질의인터뷰기법.md)
- 작성 예시: [장학금 탐색 맥락질의](05_맥락질의_작성예시.md)
- 수행 방식: AI 기반 고령자 페르소나 시뮬레이션 맥락질의 (실제 현장 섭외 및 관찰 환경의 제약으로 인해 생성형 AI를 활용하여 정밀 페르소나 구축 후 모의 인터뷰 수행)
- 권장 시간: 준비 15분 + 수행 15분 + 분석 30분
- 최종 산출물: 시간순 관찰기록, 핵심 사건 3개, 인사이트 3개, 설계 기회 2개

## 0. 활동 원칙

- **환경적 제약 보완**: 실제 매장 내 고령자 대면 섭외 및 현장 관찰 진행이 어려운 환경적 한계를 고려하여, 고령자 인지·신체적 특성을 정밀 반영한 AI 페르소나를 구축해 가상 맥락질의를 진행합니다.
- 참여자가 실제 키오스크 UI 플로우를 단계별로 마주하는 상황을 시뮬레이션하여 실제 과업을 수행하게 합니다.
- 연구자는 정답을 유도하지 않고, 각 화면 인터랙션 직후의 행동 이유와 발화를 확인합니다.
- 관찰 사실, 발화, 연구자 추론, 참여자 확인 결과를 명확히 분리합니다.
- AI 편향을 방지하기 위해 비현실적이거나 과장된 시나리오는 배제하고 표준적 고령자 멘탈 모델에 근거하여 기록합니다.

## 1. 실습 대상

| 항목 | 작성란 |
|---|---|
| 선택한 장소·과업 | 맥도날드 매장 내부 터치스크린 키오스크 앞, 손주를 위한 버거 세트 메뉴 선택 후 사이드 변경 및 신용카드 결제 완료 |
| 참여자 포함 기준·가명 | AI 구축 페르소나: 만 68세, 남성, 스마트폰 기본 기능 및 타 기관 무인민원기 사용 경험 유, 맥도날드 키오스크 첫 이용자, 돋보기안경 착용, 노안 및 조작 실패 두려움 보유 ※ 오프라인 현장 고령자 섭외가 어려운 상황으로 생성형 AI 기반 페르소나로 모델링함 |
| 조사 목표 | 화려한 시작 광고 속 '주문하기' 버튼 식별 과정, 메뉴 상세 내 토핑/사이드 변경 버튼 직관적인 확인 여부, 결제 직후 부가 서비스(테이블 서비스) 화면 직면 시 루프 단절 원인 규명 |
| 관찰 시작·종료 조건 | 시작: 키오스크 대기열에서 차례가 되어 시작 광고 화면 앞에 섰을 때 / 종료: 카드 결제 승인 후 영수증과 주문 번호표를 수령한 순간 or 결제시 어려움으로 인해 주문을 포기하는 순간 |
| 촬영·녹음 여부와 동의 | 가상 페르소나 시뮬레이션 진행으로 실제 인물 대체 (AI 인터랙션 프롬프트 및 시뮬레이션 대화 로그 전량 기록·보관, 개인정보 침해 위험 없음) |
| 중단 조건 | 페르소나 프롬프트 상 인지 과부하 시나리오 도달 또는 심리적 압박감으로 인한 이탈 시 즉시 단계 중단 및 원인 분석 |

## 2. 시작 안내

> 오늘은 사용자를 평가하는 것이 아니라 서비스와 작업 과정을 이해하려고 합니다. 평소처럼 수행해 주세요. 원하지 않는 질문에는 답하지 않거나 언제든 중단할 수 있습니다.

내가 추가할 안내 (AI 페르소나 시스템 프롬프트 및 시작 안내):

> "당신은 68세 고령 사용자입니다. 키오스크 사용경험이 있습니다. 맥도날드 키오스크는 손주 간식을 사주기 위해 마주했습니다. 눈이 침침하여 돋보기를 썼고, 뒤에 줄 선 사람들 때문에 긴장된 상태입니다. 기계가 낯설더라도 어르신의 잘못이 아니니 자책하지 마시고, 화면을 보면서 떠오르는 생각, 헷갈리는 부분, 당황스러운 느낌을 솔직하게 소리 내어 말씀해 주세요."

## 3. 관찰 초점

| 초점 | 찾은 내용 1 | 찾은 내용 2 |
|---|---|---|
| 행동 순서 | 시작 광고 화면 응시 → 버거 카테고리 선택 → 버거 세트 터치 → 변경 없이 장바구니 담기 | 장바구니 목록 확인 후 취소 → 사이드 변경 버튼 재탐색 및 치즈스틱 선택 → 결제하기 터치 → 테이블 서비스 화면에서 '이전' 연타 → 카운터 픽업 재선택 후 카드 결제 |
| 사용하는 도구·정보 | 대형 터치스크린, 화면 상단 광고 영상, 화면 하단 작은 버튼 글씨 | 물리적 카드 삽입구, 초록색 점멸 LED, 영수증 배출구 |
| 중단·방해 | 화면 전체를 채우는 화려한 동적 광고로 인해 '주문하기' 버튼 위치를 즉각 파악하지 못하고 시선 정체 | 결제 직전 불필요하게 팝업된 '테이블 텐트/진동벨 번호 입력' 화면으로 인한 조작 당혹감 및 중단 |
| 우회 방법 | 변경 버튼을 인지하지 못해 일단 장바구니에 담은 후 수량을 확인하다가 삭제하고 다시 메뉴 화면으로 진입 | 테이블 번호 입력창에서 당황하여 화면 상단의 '이전' 버튼을 2회 연속 클릭해 이전 단계로 되돌아간 뒤 재시도 |
| 오류·복구 | 사이드 메뉴가 기본으로 담겨 삭제 후 재탐색하는 오류 복구 과정 발생 | 카드 삽입구에 카드를 마그네틱 방향으로 잘못 삽입했다가 화면의 실패 안내 음성을 듣고 IC칩 방향으로 재삽입하여 승인 완료 |

## 4. 시간순 관찰 기록

> ※ 실제 매장 현장에서 고령자 관찰이 어려운 환경적 제약을 고려하여, 실제 맥도날드 키오스크 UI 화면 흐름을 단계별로 제공하고 사전에 정밀하게 설계된 고령자 AI 페르소나가 실시간으로 취한 행동과 발화를 관찰·기록한 자료입니다.

| 시간 | 관찰 사실·행동 | 사용자 발화 | 연구자 추론 | 사용자 확인 결과 |
|---|---|---|---|---|
| 01:10 | 시작 화면 상단의 대형 버거 프로모션 동영상을 약 8초간 응시하며 머뭇거리다가, 화면 하단 구석의 작은 '주문하기' 버튼을 조심스럽게 터치함 | “이게 지금 주문하는 게 맞나? 그냥 TV 광고 화면인 줄 알았네.” | 광고의 시각적 영향력이 압도적이어서 시작 버튼의 기표와 가시성이 결여됨 | 화면이 계속 번쩍거리며 움직여서 손을 대면 안 되는 안내용 화면인 줄 알았다고 답함 |
| 03:45 | 추천/버거 메뉴에서 '빅맥 세트'를 터치한 뒤 세부 옵션 화면으로 진입함. 상품 사진과 이름만 쳐다보고 하단의 작은 변경 버튼들을 지나쳐 곧바로 '장바구니 담기' 버튼을 터치함 | “손주가 감자튀김 말고 치즈스틱 먹는댔는데... 일단 담아야 하나?” | 상품 이미지 대비 변경 버튼의 크기와 대비가 작아 상호작용 가능한 요소로 인식하지 못함 | 버튼의 크기가 작아서 변경 가능한지 모르고 넘겼다고 답함 |
| 06:20 | 장바구니에 '기본 감자튀김'이 담긴 것을 확인하고 터치를 멈춤. 삭제(X) 버튼을 눌러 메뉴를 비운 뒤 다시 빅맥 세트를 선택하고 돋보기를 고쳐 쓰며 화면 하단을 정밀 탐색함 | “어라? 치즈스틱은 어디서 바꾸는 거지? 아이고, 여기 밑에 숨어 있었네. 글씨가 너무 작아.” | 필수 옵션 변경 유도가 미흡하여 오류 복구를 위한 탐색 및 조작 비용이 크게 발생함 | '사이드 변경' 글씨가 너무 작고 누를 수 있는 단추인 줄 전혀 몰랐다고 답함 |
| 08:30 | 작은 '사이드 변경' 버튼을 누른 후 '치즈스틱'을 선택하고 장바구니에 정상 반영된 것을 확인함 | “휴, 이제야 제대로 들어갔네. 바꾸기 참 힘드네.” | 복잡한 계층 구조 속에서 과업을 간신히 완수했으나 인지적 피로감이 누적됨 | 손주가 좋아하는 메뉴라 포기하지 않고 찾았지만 혼자 왔으면 그냥 기본으로 먹었을 것이라 답함 |
| 10:15 | 하단의 '주문내역 확인 후 결제하기' 버튼을 누름. 추천 사이드 추가 팝업이 뜨자 '선택 안 함'을 침착하게 누름 | “자꾸 뭘 더 사라고 묻네. 바로 계산하면 되는데.” | 추천 상품 단계로 인해 결제가 지연되고 피로도가 증가함 | 계산하려는데 다른 음식을 또 권해서 번거로웠다고 답함 |
| 11:20 | 테이블 서비스 선택 화면이 나타나며 '테이블 텐트/진동벨 번호를 입력하세요'와 숫자 키패드가 화면에 크게 표시되자 손을 멈추고 굳어짐 | “어? 난 카드로 돈 내려고 했는데 왜 진동벨 번호를 쓰라고 하지? 내가 뭘 잘못 눌렀나 보다.” | 결제 직전 예상치 못한 부가 과업 강제로 사용자가 과업 오류로 오인하고 심리적 불안 유발 | 돈 내는 화면이 안 나오고 모르는 번호를 넣으라고 하니 주문이 꼬인 줄 알았다고 답함 |
| 11:45 | 화면 상단의 '이전' 버튼을 2회 연속 터치하여 다시 장바구니 화면으로 돌아감 (루프 단절 발생) | “처음부터 다시 해야 하나... 뒤에 사람도 기다리는데 큰일 났네.” | 심리적 압박감 속에서 오류 상황을 안전하게 복구하고자 이전 화면으로 회귀함 | 뒤에 줄 서 있는 사람 눈치가 보여 직원에게 물어보거나 포기하고 싶었다고 답함 |
| 13:05 | 연구자의 중립적 격려 후 다시 '결제하기'를 누르고, 안내 문구를 천천히 읽은 뒤 화면 한쪽의 '카운터 직접 수령' 버튼을 찾아 터치함 | “아, 카운터에서 받는 것도 있구나. 글씨가 작아서 안 보였네.” | 카운터 수령이 자동 지정되지 않아 불필요한 인지 판단이 강제됨 | 직원이 가져다주는 서비스는 필요 없고 그냥 앞에서 받으면 되는데 복잡하게 해놨다고 답함 |
| 14:10 | 신용카드 투입 안내 화면이 나오자 지갑에서 카드를 꺼내 투입구에 넣음. 마그네틱 방향을 반대로 넣었다가 기기 음성 안내를 듣고 IC칩 방향으로 돌려 꽂아 최종 결제 및 영수증 수령을 완료함 | “드디어 끝났네! 영수증 나오는 데까지 숨이 턱턱 막혔네.” | 투입 방향 기표 부족과 긴 결제 여정으로 인한 극도의 긴장감 경험 | 카드를 넣는 구멍 그림이 너무 작아 헷갈렸지만 소리가 나와서 다행히 마칠 수 있었다고 답함 |

## 5. 해석 확인

> ※ AI 페르소나 시뮬레이션 직후, 관찰된 행동에 대한 연구자의 자의적 왜곡이나 확증 편향을 방지하기 위해 중립적 확인 질문을 던져 페르소나의 인지적 의도와 멘탈 모델을 재검증한 인터뷰 기록입니다.

| 회차 | 중립적 확인 문장 | 참여자의 답 | 수정된 해석 |
|---:|---|---|---|
